Проблема, которую решает проект

Уход вендора из России, падение производительности текущего решения при росте объема данных, его архитектурная негибкость и отсутствие вендорской поддержки ( последнее обновление ПО было в 2019г) , закрытая кодовая база, создают угрозу стабильности и развитию бизнес-процессов, вплоть до полного отказа текущей системы в ближайшие 1-2 года.

Описание проекта

Проект направлен на замену текущего программного решения ( BlueYonder (JDA), специализирующегося на пространственном и категорийном планировании и позволяет автоматически создавать детализированные промо-планограммы.
Текущее решение не позволяет адекватно масштабироваться при увеличении объёмов данных и нагрузки.
Основные причины замены связаны с необходимостью перехода на современное, производительное решение, устойчивое к росту данных, обеспечивающее высокую стабильность и безопасность.

Ограничения проекта
  1. Проект "Замена JDA CKB" реализуется для формата ГМ; СМ; Эконом; Алкомаркеты; Табакошопы; Зоомаркеты.
    Для данных форматов необходима адаптация процесса;
  2. Затраты по проекту "Замена JDA CKB" должны быть распределены между форматами ГМ; СМ; Эконом; Алкомаркеты; Табакошопы; Зоомаркеты.
