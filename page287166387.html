2.4.1. Катовер-план (план внедрения системы/переключения) [заполнить]

Артефакт проекта необходим только при переносе в продуктив изменений по CORE-системам с остановом работы систем.

Катовер-план разрабатывается с обязательным привлечением Архитектора решения.

Шаблон может быть применим для катовера технического катовера и катовера Тиражирования. Ниже пример заполнения (Общий CutOver).

Примеры катовер-плана:

Шаблон CutOver плана - Product Marking - Confluence (lenta.com)

План Запуска по 0950 Мелкий ОПТ в ТК, с ОСУ на ПУ - Единая база знаний по проектам Ленты - Confluence

План запуска по 0880 CutOverPlan Перевод с ОСУ на поштучный учет, Приемка на ТК - Единая база знаний по проектам Ленты - Confluence

Содержание шаблона катовер-плана:

  • Доработки по системам
  • Компания и режим
  • Общий CutOver
  • План отката
  • Транзакции, Фоны
  • Запросы
  • Настройки
  • Ретро переноса

Перенос изменений с остановкой работ систем применяется для Core-систем компании (SAP ERP, SAP EWM, OTM) в выходной день.

Существуют регламентные, предварительно согласованные окна остановок систем: 2-3е воскресенье месяца с 6:00 до 10:00 утра.

Важная информация по перенесу Core-систем в продуктив доступна по ссылке: Индекс важной документации - Домен IT4IT - Confluence (lenta.com)
