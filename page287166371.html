Оперативный контроль затрат на Инфоком

Нажмите здесь для раскрытия...

В Power BI настроен отчет - Учет фактических расходов PJF.

Данные по списаниям сотрудников отчет берет из Jira, Ставки сотрудников из файла EXCEL, который заполняется вручную.

Использовать его допустимо только для оперативного контроля текущего месяца, так как в Jira могут меняться привязки PJF к задачам.

При использовании отчета необходимо проверять, что у всех сотрудников указана ставка, в противном случае сумма всех затрат будет некорректна.

Итоговые файлы по закрытию Инфоком коллеги из инвестиций сводят ежемесячно  Закрытие расчеты 2025 - Все документы

Транзакции для управления бюджетом


  1. ZPS_PJF_BUDGET - это транзакция, которая позволяет сформировать отчет, отражающий общую сумму PJF, сумму всех затрат, сумму остатка по договору (облиго) и свободные средства в бюджете.
  2. ZPSP1 - транзакция, которая позволяет сформировать детальный отчет о затратах по проекту.  

Информация по Договорным документам отражается в SAP в течение 1-3 дней с момента передачи ДД в архив WSS.

ZPSP1 - просмотреть все текущие расходы

Данная транзакция отображает расходы по проекту на дату выгрузки отчета.

Оплата за Инфоком проходит в 25-30 числах следующего месяца.

В поле Классификатор проекта указываем номер PJF:


Отчет включает всю информацию по текущим затратам. Для контроля бюджета необходимы следующие столбцы:

  1. Идентификатор признака - PJF
  2. Краткое описание для признака - Название проекта
  3. Название - Номер и описание договорного документа
  4. Имя Контрагента
  5. Сумма договора  - Сумма всех законтрактованных работ по данному PJF (с НДС)
  6. Сумма платежей  - с НДС
